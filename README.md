# SOC Incident Response & Threat Intelligence | Academic Case Studies

## Overview
This portfolio repository presents **two academic group exercises** from SEC-320: incident-response planning and cyber threat intelligence analysis. The work is **scenario-based**; the reports do not establish that a live enterprise incident was investigated, contained, or remediated.

**Focus areas:** SOC triage concepts, NIST incident-response lifecycle, OODA decision-making, indicators of compromise (IOCs), threat-intelligence enrichment, MITRE ATT&CK mapping, and written response recommendations.

## Case studies

### 1. Incident Response Planning — SEC-320 Lab 1
[Read the case study](case-studies/incident-response-planning.md)

A classroom scenario involving failed authentication attempts followed by a successful login from a blacklisted IP address. The group report discussed:
- Reviewing authentication and access logs
- Planning containment, eradication, recovery, and notification
- Using the OODA loop to structure decisions
- Mapping credential misuse to **MITRE ATT&CK T1078 (Valid Accounts)**

**Scope:** Proposed incident-response actions in a simulated scenario, not verified actions performed on a production environment.

### 2. IOC Enrichment & Threat Intelligence — SEC-320 Lab 2
[Read the case study](case-studies/ioc-enrichment-threat-intelligence.md)

A group exercise covering sample IP, domain, and file-hash indicators, written threat-enrichment findings, ATT&CK technique mapping, and a simulated alert-response workflow. The original report discussed VirusTotal, AlienVault OTX, and APT28-related techniques.

**Important limitation:** The original report contains conflicting malware identifications for the same sample hash, and no retained primary lookup results are included here. Its threat attributions are **not independently verified** and should not be treated as current indicators or confirmed findings.
